# Attributions

## Inspiration and technical references

- **iPhone DUO's folding animation** inspired this independent MacBook interpretation. No Apple phone model, photographic wallpaper, or reference-recording frame is distributed in this repository or app. The sample desktop is generated by the app's own drawing code.
- **[chuspeeism/iphone-duo](https://github.com/chuspeeism/iphone-duo)** — [MIT license](https://github.com/chuspeeism/iphone-duo/blob/main/LICENSE), copyright (c) 2026 jadon7. Its [Vercel web demo](https://iphone-duo-tawny.vercel.app/) and source informed the fixed-eye projection, progressive blur, softened boundaries, and content-darkening concepts. The native Metal renderer is independently implemented; the web application's Three.js library, code, models, and image assets are not bundled.
- **[samhenrigold/LidAngleSensor](https://github.com/samhenrigold/LidAngleSensor)** — [Apache-2.0 license](https://github.com/samhenrigold/LidAngleSensor/blob/main/LICENSE), by Sam Gold. Reference for the Apple orientation sensor's discovery identifiers and feature-report format. Duo Lid implements its own read-only IOKit reader and does not incorporate the project's source or binary.

Version 0.3 also references **[jal-co/iphone-duo](https://github.com/jal-co/iphone-duo)** ([MIT license](https://github.com/jal-co/iphone-duo/blob/main/LICENSE)), the source of the user's [current Vercel reference](https://iphone-duo.vercel.app/). Its anchored content and moving blur/coverage boundary informed the revised effect. Duo Lid implements its own fixed-rectangle screenshot and black occlusion mask; none of that demo's code, models, icons, wallpapers, or Three.js library are bundled.

## Runtime dependencies

The **Duo Lid app icon** was created for this project with OpenAI's built-in image generation tool, based on the creator's closing-effect screenshot of Duo Lid's generated sample desktop. The [master, reference and generation prompt](https://github.com/StarWars/iphone-duo-closing-animation-on-macbook/blob/main/duo-animation/App/Artwork/README.md) are included in the source project. It contains no Apple logo or phone artwork.

There are **no third-party runtime libraries or package dependencies**. The app links only Apple system frameworks, including AppKit, Foundation, IOKit, ScreenCaptureKit, ServiceManagement, Metal, MetalKit, Metal Performance Shaders, QuartzCore, and Carbon. XCTest is used for development tests, not shipped in the app.

Neither Three.js nor LidAngleSensor is a dependency. An attribution to a technical reference is not a claim that its library or code is embedded in this project.

## Optional development tools

- **[XcodeGen](https://github.com/yonaskolb/XcodeGen)** generated the checked-in Xcode project from `duo-animation/project.yml`. It is not required to build that project in Xcode and is not shipped with the app.
- **MobileBuildMCP** was used locally to orchestrate macOS builds and tests. It is optional developer tooling, not an app dependency.
- **[FFmpeg](https://ffmpeg.org/)** encoded the generated sample-frame sequence into the QA preview video. Its executable and libraries are not distributed with the app.
